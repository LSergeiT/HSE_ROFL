Борьба с борщевиком

Дрон находит борщевик. Дрон его уничтожает.

Автономный комплекс на базе YOLO11 для точечного обнаружения и обработки очагов борщевика с воздуха. Экономия химикатов до 70%.

Подключить поле Тарифы
Как работает

Два дрона — один умный маршрут

1. Поле

Задайте границы поля через интерфейс — система рассчитает оптимальный маршрут облёта.

2. Разведка

Первый дрон облетает поле по алгоритму SDR-v1-1-2 и снимает территорию с воздуха.

3. YOLO11

Нейросеть автоматически обнаруживает очаги борщевика на снимках с БПЛА.

4. Проверка

Оператор-фермер подтверждает обнаруженные очаги и при необходимости корректирует карту.

5. Обработка

Второй дрон вылетает для точечного опрыскивания только выявленных очагов.

6. Отчёт

Краткий отчёт о результатах обработки: площадь, расход химикатов, карта очагов.
